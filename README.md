# PDF 转换拼接工具 v6.2

三个模式一个包：一批 Word / Excel 一键转 PDF、扫描件按顺序贴回首页、一批文件拼成一份去打印。
**免装 Python，拷到哪都能用。**

工程部门有大量文件需要统一转 PDF 归档或外发；另有一条「工程文件首页签字扫描件替换」的流程要把签完字的扫描件按顺序换回原 PDF。
转换原来单份 1~3 分钟、整批 1~2 小时；首页替换单份 2~5 分钟，文件一多顺序容易错位。现在**一键批量、分钟级完成**，替换整批一次到位。

## 目录结构

| 目录 | 说明 |
|---|---|
| `mac/` | macOS 版（`.command` 双击启动） |
| `windows/` | Windows 版（`.bat` 双击启动） |

两个目录下都是 `app/` + 一个启动器 + 一份 `说明书.md`，`app/` 内的源码在两个平台**逐字节一致**。

## 这个仓库里没有 runtime

6.2 是「免装交付」版：完整发布包自带 Python 运行时（`runtime/`）与离线 wheels，双击就能开。
`runtime/` 单平台 76~86 MB，属于二进制运行环境，不放进版本库。

**要真正运行**，拿内部共享盘 / 内部工具库网页上的完整 6.2 压缩包；或者自己补一个 Python 3.13 环境（依赖见 `app/shell/setup_env.py`），启动器会优先用包内 `runtime/`、找不到再降级到系统 Python。

## 三个模式

**① 导出 PDF**　「＋ 添加文件…」挑文件 → 看一眼产物名 → 点「开始转换」。产物落在原件旁边，原件不动。Excel 每个工作表自动各出一页；撞名会问：覆盖 / 加编号另存 / 先别跑。

**② PDF 首页替换**　加原件 → 点「预览」排队 → 填一份多页扫描件 PDF → 再「预览」→「开始替换」。
按「第 N 行 ← 扫描件第 N 页」硬对应，份数对不上整批不执行。输出文件名必须带后缀 —— 空着会盖掉原件，工具直接拦住。

**③ 合并打印**　把要拼的都挑进来 → 选打印方式（单面 / 双面 / 首页单面）→ 选页面方向 → 选输出位置 →「开始合并」。
双面模式给奇数页的份末尾补一张空白，让每份都从纸的正面开始；中间文件全在临时目录，拼完就删。有一份转不出来就**整批不生成**。

## 6.2 新增

- **首页单面 + 其余双面**：首页要单独签字 / 盖章、背面必须是空的就选这一档 —— 工具在第 1 页之后**强制插一张空白**，正文从下一张纸的正面接着印；插完再看页数，是奇数就在末尾再补一张。
  （一份 3 页的文件进去，出来是 4 页：首页 / 空白 / 2 页正文。）
- **页面方向开关**：一批里横竖混着时，把横版页统一转成竖向（或反过来），整批纸张同向再拼。默认「保持原样」，一张都不转。
  注意转方向之后横版那几页的**内容会侧躺** —— 页面转 90° 内容没法重排，只能跟着转；整批纸张同向才算对。

## 格式支持

Word / Excel / PDF；**Windows 额外支持** Visio / CAD / BarTender 标签。
限制：Word / Excel 横竖版未预判；普通 Excel（无模板、无框选打印区域）转换效果一般；BarTender 转出的标签 PDF 是图像型，文字不可读。

```bash
# 命令行体检
./runtime/bin/python3 -B app/shell/setup_env.py --check
```

调试脚本一律用包内 `runtime/bin/python3`，不要用系统 Python —— 依赖只装在包内的 runtime 里。
