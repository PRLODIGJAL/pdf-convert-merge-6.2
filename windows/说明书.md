# PDF转换拼接工具 6.2

> 三个模式一个包：一批 Word / Excel 转 PDF、扫描件按顺序贴回首页、一批文件拼成一份去打印。**免装 Python，拷到哪都能用。**

## 怎么启动

直接双击「启动PDF转换拼接工具.bat」→ 界面打开。它自带体检，小毛病自己修，
**换电脑、换盘（C 盘挪到 D 盘）都一样直接双击**，没有别的步骤。

## 怎么用

1. 顶部三个大按钮选模式：导出 PDF / PDF 首页替换 / 合并打印（三个模式的清单各记各的）
2. **导出 PDF**：「＋ 添加文件…」挑文件 → 看一眼产物名 → 点「开始转换」，各落在原件旁边，原件不动
3. **PDF 首页替换**：加原件 → 点「预览」排队 → 填一份多页扫描件 PDF → 再「预览」→「开始替换」
4. **合并打印**：把要拼的都挑进来 → 选打印方式（单面 / 双面 / 首页单面）→ 选页面方向 → 选输出位置 →「开始合并」（默认桌面上的《合集打印.pdf》）

## 这版有什么

- **免装 Python**：整个包自带运行时（runtime/），不依赖电脑上装没装 Python
- **三合一**：原来的「PDF 转换拼接」和「奇偶拼接打印」并成一个包，顶部三个模式
- **合并打印**：双面模式给奇数页的份末尾补一张空白，让每份都从纸的正面开始；中间文件全在临时目录，拼完就删
- **首页单面 + 其余双面**（6.2 新增）：首页要单独签字 / 盖章、背面必须是空的，就选这一档 ——
  工具在第 1 页之后**强制插一张空白**，正文从下一张纸的正面接着印；插完再看页数，
  是奇数就在末尾再补一张。每一份都按这个规则处理。
  例：一份 3 页的文件进去，出来是 4 页（首页 / 空白 / 2 页正文）。
- **页面方向开关**（6.2 新增）：一批里横竖混着的时候，把横版页统一转成竖向（或反过来），
  整批纸张同向再拼。默认「保持原样」，一张都不转。
- Excel 每个工作表自动各出一页；撞名会问：覆盖 / 加编号另存 / 先别跑
- 首页替换按「第 N 行 ← 扫描件第 N 页」硬对应，份数对不上整批不执行
- 格式支持：Word / Excel / PDF / **Visio 流程图 / CAD 图纸 / BarTender 标签**，Word / Excel 用本机 Office 转，保真度最高

## 注意

- 首页替换的输出文件名必须带后缀 —— 空着会盖掉原件，工具直接拦住
- 合并打印有一份转不出来就**整批不生成**（少一份的合集比报错难收拾）
- 一份 .btw 标签出两个文件（图片 + PDF）；标签 PDF 是图不是字，不能选中复制
- 转方向之后，横版那几页的**内容会侧躺** —— 页面转 90° 内容没法重排，只能跟着转。
  整批纸张方向一致才算对，别把侧躺当成出错。
- 「首页单面」插出来的空白页，尺寸跟相邻页一样（横版文档补的也是横的），打印不会错位

## 打不开 / 报错

- 双击 .bat 弹「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
- 第一次转 Word / Excel 弹系统授权：点「允许」，允许一次以后不再问。
- 说没检测到 Office / CAD：软件是工具打开之后才装的 → 点「重新检测引擎」再试。
